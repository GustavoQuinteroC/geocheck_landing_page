## Acerca de

Este repositorio contiene el código de la página pública de **GeoCheck**: la que presenta el producto, sus planes y su información legal. Está hecha a mano, sin librerías de interfaz, con atención a velocidad, accesibilidad y posicionamiento en buscadores.

## Tecnología

| | |
|---|---|
| Lenguaje | PHP 8 (sin frameworks) |
| Interfaz | HTML, CSS y JavaScript propios |
| Tipografías | Autoalojadas |
| Temas | Claro y oscuro |
| Diseño | Adaptable a celular, tableta y escritorio |

## Cómo se ejecuta

Requiere un servidor web con PHP 8 o superior y la carpeta del repositorio como raíz del sitio. No hay paso de compilación ni dependencias que instalar.
